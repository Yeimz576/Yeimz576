### 🔌 Integraciones con ERPs

Conecto NetSuite, SAP S/4HANA, SAP Business One, Business Central, Odoo y Siigo con la plataforma, y sincronizo proveedores, facturas, órdenes de compra, recepciones, pagos y catálogos contables. He puesto en marcha clientes de distintos sectores y países, cada uno con su configuración por cliente y por sociedad.

- Reemplacé el servicio de terceros que generaba las conexiones con los ERPs por un sistema propio, lo que redujo costos
- Diseñé modelos reutilizables con el patrón Strategy por ERP: integrar un cliente con NetSuite pasó de **2 días a unas pocas horas**
- Centralicé la salida de peticiones en un builder, lo que simplificó el manejo de headers, autenticación y la depuración

### 💳 Pagos y banca

- Pagos con tarjeta, recurrentes, a cuotas y suscripciones
- PSE, 3D Secure, Transfiya y Simetrik (conciliación)
- Plugin de WordPress que conecta comercios e-commerce a la pasarela
- Lotes de pago, archivos planos bancarios y comprobantes

### ⚙️ Backend y arquitectura

- Separación de monolitos en servicios con responsabilidad y tecnología propias
- Colas independientes para actualizar y notificar transacciones
- Clean Architecture y patrones Strategy, Repository y Factory
- Optimización en PostgreSQL con **30–40 % de mejora** de rendimiento en producción
- Pruebas automatizadas, incluidas pruebas de caos contra los errores de los ERPs
- AWS (Lambda, Secrets Manager, KMS, VPC, EventBridge), Terraform y GitHub Actions

### 🤖 IA aplicada al desarrollo

- Convierto el conocimiento de cada ERP en skills de IA, lo que acelera la integración de nuevos clientes
- Uso la metodología compound: lo que se aprende en cada tarea queda como regla o skill que el agente reutiliza
- Optimizo el contexto de los proyectos para que el agente cargue solo lo necesario, con menos tokens y mejores resultados
- Construyo herramientas de Claude Code para el flujo de desarrollo del equipo
